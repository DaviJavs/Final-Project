# Final Project: Git and GitHub Hands-On

This project is part of the final assignment for the Git and GitHub hands-on labs. The main objectives of this project are:

- To demonstrate the ability to use Git and GitHub effectively.
- To manage repositories using GitHub’s user interface.
- To fork repositories, make changes, and manage branches using the Git CLI.
- To follow best practices for open-source collaboration including licensing, documentation, and community standards.

## Features

- Apache 2.0 License included
- Community standards: README, License, Code of Conduct, and Contributing guidelines
- `simple-interest.sh` script included for demonstration purposes

## Getting Started

1. Clone the repository
2. Run `simple-interest.sh` using a terminal
3. Follow contributing guidelines for submitting changes
